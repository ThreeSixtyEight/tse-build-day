Build Day is simple: one day, the whole team, one thing we ship by the end of it. Designers write code, engineers write copy, strategists push pixels.

This quarter we're rebuilding our own site — and we're doing it in the open.

## How to contribute

Everything you see here lives in plain Markdown and JSON inside the repo. Want to add a case study? Drop a new file into the work folder. New teammate? Add them to the team list. No CMS login required.

## What comes next

Content lives in Astro content collections today, but every collection sits behind a loader. When we're ready to plug in WordPress or Contentful, we swap the loader — not the pages.
